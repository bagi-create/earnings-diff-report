# 決算差分レポート（Earnings Diff Report）

前回と今回の決算資料（決算短信・決算説明資料など）を比較し、

- 追加・削除・言い換えられた文言を文単位で洗い出す
- トーンの変化（例：中立 → 強気）をスコアで示す
- 事業環境の変化を観点別（需要／価格・原価／為替／供給・調達／見通し・還元）に整理する

ための Web アプリです。投資助言ではなく、決算資料の「文言の変化」を短時間で把握するための情報整理ツールとして設計しています。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

本番ビルド:

```bash
npm run build
npm run start
```

API キーは不要です（MVP はルールベース解析のみで動作します）。

## 使い方

1. 前回と今回の決算資料を PDF でアップロードするか、本文テキストを貼り付けます（PDF のテキスト抽出はブラウザ内で行います）。
2. 「差分を解析」を押すと、トーン変化・要約・事業環境の変化・文言差分が表示されます。
3. サンプル（中立→強気／強気→慎重）が入っているので、資料がなくても動作を確認できます。
4. レポートは .txt で保存できます。

## 解析の考え方

- 文単位に分割し、正規化（空白・記号除去）したうえで完全一致を「変更なし」とします。
- 残った文同士を文字バイグラムの類似度で突き合わせ、類似度が高いペアを「言い換え」、残りを「追加」「削除」とします。
- トーンは、強気・慎重キーワードの重み付き出現数でスコア化し、強気／やや強気／中立／やや慎重／慎重に分類します。
- 事業環境は、観点別キーワードに触れた変更文を集めて表示します。

## 注意

- PDF のレイアウトによってはテキスト抽出の精度が落ちます。その場合はテキスト貼り付けを使ってください。
- 本ツールは決算資料の文言変化を整理するもので、特定銘柄の売買を推奨する投資助言ではありません。
