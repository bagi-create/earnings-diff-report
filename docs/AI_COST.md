# AIモデルの選び方と費用の抑え方

2026年10月27日時点の Gemini API 公式価格（有料枠、100万トークンあたり）にもとづく。

## 結論

| 用途 | モデル | 理由 |
| --- | --- | --- |
| Web画面での都度解析（既定） | `gemini-3.5-flash-lite` | 入力 $0.30／出力 $2.50。安定版（GA）で、値上げの予定がない |
| TOPIX一括の事前生成（将来） | `gemini-3.8-flash` を Batch API で | 品質が一段上。Batch は半額。件数が決まっているので総額も小さい |

「Gemini 3.7 Flash」というモデルはない。Flash 系の現行は 3.8 Flash（最新）と 3.6 Flash（前世代）。
3.8 Flash は入力 $0.75／出力 $3.75 だが、**2027年1月1日に倍額**（入力 $1.50／出力 $7.50）になる予定。
2.5 系は新規利用が制限されており、新しいプロジェクトには勧められていない。

モデルは環境変数 `GEMINI_MODEL` で切り替えられる（コードの変更は不要）。

## 1回あたりの費用

AIに送るのは、ルールベース解析で重要度が高かった変更点だけ（最大60件・合計14,000字）。
資料の全文は送らない。出力は最大2,500トークンに制限している。

| モデル | ふつうの資料（入力約5千／出力約800トークン） | 上限いっぱい（入力約1.2万／出力2,500） |
| --- | --- | --- |
| 3.5 Flash-Lite | 約0.5円 | 約1.5円 |
| 3.8 Flash（〜2026年末） | 約1円 | 約2.8円 |
| 3.8 Flash（2027年〜） | 約2円 | 約5.5円 |

※ 1ドル150円で換算。実際の値は画面のAI要約の下に表示される（トークン数と概算額）。

## 費用が跳ね上がらない仕組み

1. **入力の上限**：送る変更点を重要度順に件数・文字数で切る。サーバー側でも同じ上限をかけ直す（ブラウザからの送信は信用しない）。
2. **出力の上限**：`maxOutputTokens: 2500`。思考（thinking）は最小レベルにする。思考トークンは出力として課金されるため。
3. **キャッシュ**：同じ比較のAI要約は保存し、2回目以降は Gemini を呼ばない（Cloudflare KV を設定した場合）。
4. **1日の上限**：`AI_DAILY_LIMIT`（既定300回／日）を超えたら、その日はルールベース解析のみで表示する。
   KV を設定するとインスタンスをまたいで数えられる。未設定時はインスタンスごとの目安になる。
5. **Google 側の上限**：Google AI Studio／Cloud Console の予算アラートと、プロジェクトの支出上限も合わせて設定しておく。

### KV の設定（キャッシュと1日上限を有効にする）

```bash
npx wrangler kv namespace create REPORT_CACHE
```

表示された id を `wrangler.jsonc` に追記する：

```jsonc
"kv_namespaces": [{ "binding": "REPORT_CACHE", "id": "<表示された id>" }]
```

KV の無料枠（読み取り10万回／日、書き込み1千回／日）で、当面は足りる。

## TOPIX 一括生成の見積もり

TOPIX 構成銘柄（約1,700〜2,100社）× 年4回 ＝ 年8,000件前後。

| モデル | 1件（ふつうの資料） | 年間（Batch API・半額） |
| --- | --- | --- |
| 3.5 Flash-Lite | 約0.5円 | 約2千円 |
| 3.8 Flash（2027年価格） | 約2円 | 約8千円 |

事前生成なら件数が決まっているので、上位モデルを使っても年1万円に届かない。
都度解析はユーザー数に比例して増えるため、こちらは安いモデルと上限で守る、という使い分けにする。
