# マネタイズ設計メモ

## 前提

売買推奨などの投資助言に踏み込まない。「資料の変更点の整理・要約」ツールとして提供し、
金融商品取引法上の投資助言業登録が不要な範囲に建て付ける。

## プラン案

| プラン | 価格（想定） | 内容 |
| --- | --- | --- |
| Free | ¥0 | 月3回まで解析、サンプル利用、レポート保存 |
| Pro | ¥980/月（想定） | 解析回数無制限、ウォッチ銘柄登録、決算発表時の自動差分レポート配信、履歴保存 |
| Team | 要相談 | 複数人利用、共有フォルダ、API連携 |

## 継続課金の核

単発の解析よりも、「ウォッチ銘柄の決算が出たら自動で差分レポートが届く」体験が
継続理由になる。TDnet の適時開示フィードと連携し、発表検知 → 前回資料と突合 →
レポート生成 → メール/LINE 通知、までを自動化するのが本命機能。

## 集客

- 投資ブログ（SEO/AIO）と連携し、無料版を集客装置にする
- 決算シーズンに合わせた「主要銘柄の文言変化まとめ」コンテンツを公開し、Pro へ誘導する

## 実装メモ

- 課金: Stripe（Checkout + Customer Portal）
- 利用回数の制限: ユーザーごとの解析履歴を DB に保存し、プラン別に制御
- 配信: メール（Resend など）または LINE Messaging API
